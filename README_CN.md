# ShadowTrainer

[English](README.md) | [中文](README_CN.md)

一个适用于 Windows 的内存扫描器与修改器，以单 x64 DLL 形式发布。
将其加载到目标进程后，会启动一个专属窗口，用于扫描、编辑并锁定该进程的内存。
无需驱动、服务、辅助可执行文件或在宿主程序旁写入额外文件，也无需单独的目标选择器—它被加载进哪个进程，该进程**即**为目标。

![内存扫描页面](docs/img/webui/scan.png)

用户界面基于 WebView2 构建。界面资源被编译进 DLL 并通过虚拟源（virtual origin）提供服务，
因此不会读写磁盘；若缺失 WebView2 运行时，仅会导致 UI 降级，而不会中断会话。

## 功能特性

**扫描** — 包含七个功能页面：扫描、地址列表、内存预览、内存区域、模块、线程和指针扫描。

|            |                                                              |
| ---------- | ------------------------------------------------------------ |
| 数值类型   | 字节 (Byte)、2/4/8 字节（有符号、无符号、十六进制）、浮点数 (Float)、双精度浮点数 (Double)、UTF-8、UTF-16LE、字节数组 (AOB) |
| 首次扫描   | 精确值、初始值未知、大于、小于、介于                         |
| 后续扫描   | 支持上述所有方式，外加：已改变/未改变、增加/减少、增加/减少指定数值 |
| 文本与 AOB | 精确匹配及固定宽度下的“已改变/未改变”；AOB 支持通配符 `??`、`A?`、`?F` |
| 浮点数     | 精确匹配，以及参考实现中的“舍入 (Rounded)”、“舍入 (极端/extreme)”、“截断 (Truncated)”模式 |
| 结果       | 写入文件、分页显示、支持取消、支持一级撤销；取消操作不会覆盖之前成功的扫描结果 |

**地址列表** — 支持添加、编辑和删除记录；每条记录包含描述、类型、数值及锁定状态；
支持最多 16 级的指针链，且每次写入时都会重新解析，确保锁定的数值始终跟随其基址指针。如果某条记录的锁定范围与另一个已锁定的范围重叠，该操作将被拒绝，而不会静默写入。

**内存预览** — 一个 256 字节的十六进制/ASCII 视图页，支持十种显示模式（字节，以及 2、4、8 字节的十六进制与十进制格式，外加单精度/双精度浮点数）。字节支持原地编辑：十六进制单元每次输入半字节（nibble）并显示待定数字；十进制和浮点数单元在按下 Enter 键时提交更改，按 Esc 键取消；所有写入操作（包括在网格上拖动进行的范围填充）都会记录在包含 256 个条目的撤销堆栈中。“后退”和“前进”功能用于在已访问的页面间切换。

**指针扫描** — 从目标地址反向搜索多级指针路径，支持可选的静态模块过滤器，生成的记录可直接添加到地址列表中。四项限制参数（收集槽位、每个节点的唯一偏移量、每层节点数、结果总数）均会明确显示而非隐藏：一旦触及限制，结果集将被截断并提示相关信息。

**进程视图** — 显示宿主进程的内存区域（Regions）、模块（Modules）和线程（Threads），每次刷新时生成一致的快照。视图为只读模式，并受访问掩码（access mask）限制：线程以 `THREAD_QUERY_LIMITED_INFORMATION` 权限打开，因此程序无法挂起、恢复或终止线程。内存保护属性、线程优先级和模块列表均不会被修改。

**作弊表（Cheat tables）** — 采用经典的 XML 格式，支持严格的 32 位有符号整数子集（v1）及扩展类型（v2）。导入其他工具生成的文件时，不会丢失本项目无法解析的内容：未知元素会被保留并原样写回；无法执行的记录类型（如自动汇编脚本等）将作为只读的“不透明”行导入，并在导出时保持字节级完整。

**热键** — 使用反引号键（`）切换窗口显示状态。仅采用轮询（sampling）方式，不使用键盘钩子：不会拦截宿主程序的输入，宿主程序自身的按键功能不受影响。 ## 要求

- Windows 10 或 11，**仅限 x64 架构**。
- 构建环境：需安装包含“使用 C++ 的桌面开发”工作负载（VS18 / MSVC）的 Visual Studio 以及 Windows SDK。`build.cmd` 脚本在文件头部硬编码了 VS 的安装路径；若您的安装路径不同，请修改该行。
- 运行环境：需安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。若未安装，程序仍可运行，但界面将无法显示，取而代之的是一张提示缺失该组件的卡片。

没有其他依赖项。WebView2 SDK 已包含在 `third_party/webview2/` 目录下，并链接了其**静态**加载器（static loader）——因为当模块被加载到外部进程时，无法依赖并排部署的 `WebView2Loader.dll`。若构建过程中检测到动态链接导入了该 DLL，`build.cmd` 将会报错并终止构建。

## 构建

```bat
build.cmd
```

生成文件：`dist/x64/shadowtrainer.dll`。不包含安装程序或打包步骤。

## 加载

可使用任何标准的加载方式，如 `LoadLibraryW`、调试器或注入器；本项目不提供此类工具。DLL 一旦加载，便会立即启动其专属窗口。

若外部调用者需要控制该窗口，应持有加载引用并遵循以下流程：请求停止 -> 等待停止完成 -> 释放 DLL。停止操作会卸载模块，因此若需再次使用，必须重新加载 DLL。

| 窗口交互协议 |                                                              |
| :----------- | :----------------------------------------------------------- |
| 窗口         | 一个不归属特定进程、带有 `SHADOWTRAINER_WINDOW` 属性的顶级窗口 |
| `WM_APP+1`   | 显示                                                         |
| `WM_APP+2`   | 停止                                                         |
| `WM_APP+3`   | 切换（显示/隐藏）                                            |
| `WM_CLOSE`   | 隐藏窗口；不会停止会话                                       |

隐藏操作不会停止扫描或冻结。

## API

`include/ce/api.h` 和 `include/ce/api_v2.h` 均为纯 C 语言接口，总计包含 47 个导出函数：版本 1 包含 17 个函数（自定型后未作更改）；版本 2 包含 30 个函数，新增了显式结构体版本控制、调用者提供的缓冲区以及扩展类型支持。版本 1 不会被废弃，也不会被静默截断——如果使用 v1 接口调用无法由其表示的会话，请求会被拒绝，而不是进行数值舍入处理。

所有操作均为同步执行，不涉及回调机制。典型的 v2 接口调用接收缓冲区及其容量作为参数，并返回所需大小；因此，当以 `(nullptr, 0)` 调用同一函数时，它会返回“需要多少空间”这一信息。

关于边界条件、精确的比较与舍入语义，以及各版本拒绝处理的具体情况，请参阅 [`docs/COMPATIBILITY.md`](docs/COMPATIBILITY.md)。 ## 仓库结构

```
include/ce/    公共 ABI：api.h (v1) 和 api_v2.h (v2)
src/core/      扫描引擎、类型化读写层、指针扫描器
src/ui/        窗口、WebView2 宿主、启动封面、热键
src/bridge/    JS↔C++ 命令桥接及其 JSON 定义
web/           网页：index.html、css/、js/、img/
third_party/   WebView2 SDK（头文件、静态加载器、微软许可协议）
docs/          子系统文档（中英文）
```

`src/runtime.cpp` 是顶层唯一的编译单元；每个模块目录都被视为独立的头文件包含根目录。`web/` 目录下的页面直接从磁盘加载——资源路径既用作 URL 也用作文件位置，因此 `web/index.html` 可以独立运行，且样式和脚本均能正常工作。

## 开发界面

```bat
build\x64\dev_host.exe --dev
```

`dev_host` 会在进程内加载 DLL，并从磁盘读取 `web/` 目录的内容（而非使用嵌入式副本），因此修改样式表后只需按 F5 刷新即可，无需重新构建。[`docs/WEBUI.md`](docs/WEBUI.md) 详细介绍了页面、资源处理流程、桥接协议以及 WebView2 的生命周期。

## 状态

本项目目前仍在开发中，且有意限制了功能范围，这一点需要明确说明。已实现并经过测试的功能包括：扫描、地址列表、冻结、十六进制编辑器、指针扫描器、进程视图、作弊表（cheat-table）导入/导出以及整个用户界面。以下功能**尚未**实现，也未提供虚假的占位实现：调试器、反汇编与汇编、Lua 脚本、自动汇编（Auto Assembler）执行、训练目标格式、符号与结构体处理、插件系统、Mono/CLR/Java 支持以及变速功能（speedhack）。

驱动程序、DBVM以及远程服务功能明确不在本项目的范围内；扫描非加载该模块的进程也不在范围内。

`docs/FEATURE_PARITY.md` 逐项列出了已实现、部分实现及尚未实现的功能。如果您想了解某项功能是否可用，请在阅读代码前先查阅该表格。
