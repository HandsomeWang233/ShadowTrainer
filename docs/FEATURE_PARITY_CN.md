# 功能对等矩阵（阶段 2）

[English](FEATURE_PARITY.md) | [中文](FEATURE_PARITY_CN.md)

实现状态与测试是否通过分开判定；最终证据是本机的构建与测试运行（见 [`STATUS_CN.md`](STATUS_CN.md) 中的证据策略）。原始 CE 源码永不修改。已退役的原生 UI 的源码、测试与探针冷存于 `baseline/pre-webui/`（仅归档）。

状态取五个值：**已实现**、**部分实现**、**未实现**、**受阻**、**已放弃**。标记为部分实现的行是一个刻意划定的子集；验收边界说明边界落在何处。

## 宿主与会话

引导、窗口生命周期，以及唯一那个全局热键。

| 能力项 | 状态 | 验收边界 |
|---|---|---|
| 自动 DLL UI、默认宿主、停止与卸载 | 已实现 | 自建宿主，以普通的 LoadLibrary 加载；延续自上一阶段，并在此重新验证。它不能替代真正的注入器或 CE Tutorial。 |
| 反引号菜单切换 | 已实现 | 前台 PID、松开后触发（release-armed）、16 ms 采样、窗口隐藏后仍可切换；FSM 与共享的窗口切换路径均已测试。 |

## 扫描

数值扫描、其结果，以及指针扫描器。

| 能力项 | 状态 | 验收边界 |
|---|---|---|
| 整数 1/2/4/8、有符号/无符号、十六进制 | 已实现 | 整数不经过 double；边界与溢出测试。 |
| Float/Double | 已实现 | NaN/Infinity 与原始字节变化规则；`CeScanRequestV2.rounding` 提供 Rounded/Extreme/Truncated，且仍默认本构建原有的 Exact；仅适用于精确的 Float/Double。 |
| UTF-8 / UTF-16 / AOB | 已实现 | 65536 字节上限、全字节与半字节掩码、跨页重叠测试。 |
| 未知值、介于、大于、小于、已改变、已增加、已减少、增加/减少量 | 已实现 | 适用于数值类型；文本与 AOB 仅接受精确、已改变与未改变。 |
| 文件承载的结果、分页、取消、单级撤销 | 已实现 | 元数据与历史作为同一单元提交；代际不匹配会被拒绝，因此分页不会混入不同代际；不是原始 CE 的结果文件格式。 |
| 指针扫描（单次反向查找） | 部分实现 | 最多 8 级、对齐 1/2/4/8、最大偏移至多 0x100000、可选的静态模块过滤（在已加载模块内产出一个节点并停止向下递归）。四项上限（4M 采集槽位、每个节点 16 个不同偏移、每级 200k 个节点、65536 条结果）会置位 `truncated`，并仍然返回找到的结果；每个候选在被列出前都会重新解析。没有结果重扫或表复用，没有堆块过滤，没有指针图；UI 始终启用 NO_LOOP。 |

## 记录与内存

地址列表、指针链解析，以及内存预览页面。

| 能力项 | 状态 | 验收边界 |
|---|---|---|
| 带类型的读写、冻结、地址列表增删改查 | 已实现 | 稳定 ID；80 ms 冻结节拍；重叠的已启用冻结会被拒绝；一次失败的冻结写入会禁用该冻结。 |
| 指针链、模块 + 偏移 | 部分实现 | 基础解析：最多 16 级、宿主指针宽度、每次冻结时重新解析。这是记录解析，不是上文列出的指针扫描。 |
| 地址表达式 | 部分实现 | CE 的数值/模块子集：多 token 的 `+ - *`、`--` 视作 `+`、带引号的模块名、溢出与地址空间检查。没有符号、`[]` 解引用、`(TYPE)` 强制转换、括号或除法。 |
| Hex/ASCII 预览 | 已实现 | 256 字节分页；不可读的单元会被标记且无法编辑；不是反汇编器。 |
| Hex 视图中的字节编辑 | 已实现 | 点击 hex 或 ASCII 列会选中整个单元（而非单个半字节）；键盘无需先点击即可移动与输入。半字节逐个输入，暂存中的数字可见，只有填满后才写入该单元；不可读的单元无法编辑。 |
| 显示类型 | 已实现 | 十种模式（十六进制与十进制下的 Byte / 2 / 4 / 8 字节，外加 Float 与 Double）；单元宽度与 ASCII 列随模式变化。hex 单元是按地址顺序排列的字节序列（`CE_WriteBytesV2`）；十进制与浮点单元是字面量（`CE_WriteValueV2`，Enter 提交，Esc 取消）。 |
| Hex 视图撤销 | 已实现 | 环形缓冲至多 256 项，保存每次写入前后的字节；按钮或 Ctrl+Z。写入之后宿主改动过的字节仍会被恢复，状态行也会说明这一点。 |
| Hex 视图填充 | 已实现 | 在网格上拖动选择一个字节区间（或 Shift+点击）；逐字节解释；空选区会被拒绝；整个区间必须可读；一次写入记录一条撤销项。 |
| 后退/前进页面历史 | 已实现 | 保存已解析基址加上页码；与当前页相同的项会被丢弃；地址与偏移字段不会被改写；这是页面历史，不是表达式历史。 |

## 进程视图

宿主进程的区域、模块与线程。三者均为只读。

| 能力项 | 状态 | 验收边界 |
|---|---|---|
| 内存区域列表 | 已实现 | 只读。连续平铺整个应用地址范围，包括 MEM_FREE；base/size/state/protect/allocation-protect/type；保护属性从不修改。 |
| 模块/DLL 列表 | 已实现 | 只读。Toolhelp32 快照；base/size/name/path（path 是固定 260 字符的拷贝，会被截断）；不加载、不卸载、不注入。 |
| 线程列表 | 已实现 | 只读。TID/优先级/创建时间/名称/当前标志；线程仅以 `THREAD_QUERY_LIMITED_INFORMATION` 打开，因此**无法**挂起或恢复。 |

## 作弊表与 ABI

CT 导入/导出与公开的 C ABI。

| 能力项 | 状态 | 验收边界 |
|---|---|---|
| 扩展 CT 的数值/文本/AOB/偏移 | 部分实现 | 严格子集：CodePage=1 与 ZeroTerminate=1 会被拒绝；导入永不自动激活记录。 |
| 外部 CT 宽容导入 | 已实现 | 未知的条目子节点与顶层同级节点会被保留并原样写回；未知 VariableType 会作为只读的不透明记录导入，拒绝写入/冻结/编辑，但可删除；被保留的子树上限为 4 MiB；重新序列化在语义上等价，而非字节一致。 |
| V1 CT 路径 | 已实现 | 未变：仍是严格的 signed32 子集；脚本、偏移或未知字段会导致整张表被拒绝。 |
| V1 接口 | 已实现 | 保留：版本 1 的 17 个原始导出；它无法表示的会话会被拒绝，绝不会被隐式截断。 |
| V2 接口 | 已实现 | 新增：显式的结构体版本与调用方缓冲区；共享会话生命周期。 |

完成本阶段并不意味着重构已经完成；没有任何未实现的能力会用空函数或总是成功的桩（stub）来模拟。
